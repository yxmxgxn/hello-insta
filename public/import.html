ハロプロ Instagram 検索

取り込み（自分用）: ブラウザで見た投稿を取って入れる。公式APIで取れない個人アカウントの分と、公式APIの遡りの先回り

合言葉

使い方

  1. このリンクをブックマークバーへドラッグ: IG取得（対象アカウントの人の投稿だけを拾う。対象が変わったらドラッグし直す）
  2. 並べて取るときは、これもドラッグ: IG窓（見ている Instagram のページを、画面幅の 1/4 の細い窓で開き直す。押すたびに左から順に並ぶ。開いた窓の中で「IG取得」を押す）
  3. Graph API とは別のアカウントでログインしたブラウザで、取りたい人のプロフィール（instagram.com/ユーザー名/）か、ホームのフィードを開いて押す（対象外の人の投稿は、画面にあっても拾わない）
  4. 右下にパネルが出るので、スクロールして投稿をためる（本文が欲しい投稿は開くと拾える）
  5. 「送る」でこのページに渡す（渡らないときは「コピー」して下に貼る）→「登録」
  6. 新着を取るときは、下の表の「最新」の日時の投稿が見えるところまでスクロールしてから送ると、抜けが出ない
