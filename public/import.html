合言葉

使い方
  1. IG取得: Graph API とは別のアカウントでログインしたブラウザで、取りたい人のプロフィールかホームのフィードを開いて押す。対象アカウントの人の投稿だけを拾う（対象外の人は画面にあっても拾わない）
  2. IG窓: 見ている Instagram のページを、画面幅の 1/4 の細い窓で開き直し、窓の中で IG取得 を自動で始める。押すたびに左から順に並ぶ。窓は画面に見えるようにしておく（隠れると止まる）
  3. 右下のパネルで「Scroll」（自動スクロール）か手でスクロールしてためる（本文が欲しい投稿は開くと拾える）
  4. 「送る」でこのページに渡す（渡らないときは「コピー」して上の欄に貼る）→ 中身を確かめて「登録」
  5. 新着を取るときは、上の表の最新の日時の投稿が見えるところまでスクロールしてから送ると、抜けが出ない
  6. 対象アカウントが変わったら、IG取得 と IG窓 をドラッグし直す
  7. 公式APIで取れる人も取り込める（遡りの先回り）。公式APIの取得はそのまま続き、追いついたら公式の分（いいね数付き）に置き換わる
