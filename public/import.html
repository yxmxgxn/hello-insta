      公式APIで取れる人

      読み込み中…
      IG取得（スクロール） IG取得（一つ一つ） IG窓 ← ブックマークバーへドラッグ
      合言葉

      使い方
      1. IG取得（スクロール）: Graph API とは別のアカウントでログインしたブラウザで、取りたい人のプロフィールかホームのフィードを開いて押す。対象アカウントの人の投稿だけを拾う（対象外の人は画面にあっても拾わない）。一覧のサムネイルからは、本文が取れないことが多い（Instagram が付ける説明が、本文でなくなったため）
      2. IG取得（一つ一つ）: 本文を取るためのもの。プロフィールで投稿を1つ開いてから押し、パネルの「次へ自動」を押すと、その投稿から「次へ」を1件ずつ押して進み、開いた投稿の本文を読む。1件 2〜4.5秒で、ときどき6〜12秒休む。最初に押したときだけ、取り込みページのタブが前に出るので、Instagram のタブに戻る。40件たまるごとに、取り込みページへ送って、そのまま登録する（取り込みページを、開いておく。合言葉も覚えさせておく）。300件で止まる。開いても本文が出なかった投稿は、「本文なし」（確かめ済み）として登録され、まだ開いていない投稿の「本文未取得」と分けて数える。Instagram が制限のような表示を出したら止まる。「止める」でいつでも止められる
      3. IG窓: 見ている Instagram のページを、画面幅の 1/4 の細い窓で開き直し、窓の中で IG取得 を自動で始める。押すたびに左から順に並ぶ。窓は画面に見えるようにしておく（隠れると止まる）
      4. 右下のパネルで「Scroll」（自動スクロール）か手でスクロールしてためる（本文が欲しい投稿は開くと拾える）
      5. 「送る」でこのページに渡す（渡らないときは「コピー」して上の欄に貼る）→ 中身を確かめて「登録」
      6. 新着を取るときは、上の表の最新の日時の投稿が見えるところまでスクロールしてから送ると、抜けが出ない
      7. 対象アカウントが変わったら、IG取得（スクロール）・IG取得（一つ一つ）・IG窓 をドラッグし直す
      8. 公式APIで取れる人も取り込める（遡りの先回り）。公式APIの取得はそのまま続き、追いついたら公式の分（いいね数付き）に置き換わる
