貼り付け（自分用）: 公式APIで取れない個人アカウントの投稿を、ブラウザで取って入れる

合言葉

使い方

  1. このリンクをブックマークバーへドラッグ: IG取得
  2. Graph API とは別のアカウントでログインしたブラウザで、取りたい人のプロフィール（instagram.com/ユーザー名/）を開いて押す
  3. 右下にパネルが出るので、スクロールして投稿をためる（本文が欲しい投稿は開くと拾える）
  4. 「送る」でこのページに渡す（渡らないときは「コピー」して下に貼る）→「登録」
