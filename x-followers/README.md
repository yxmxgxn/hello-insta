# X フォロー・フォロワー保存（自分用）

X（旧Twitter）のフォロー・フォロワーを時々スプシに控えて、前回からの違い（増えた・減った・ID変更・名前変更・プロフ変更）を見るためのもの。
公式APIは使わず、x.com にログインしたブラウザで、画面が裏で読むデータを横取りする。このサイト（hello-insta）とは関係なく、デプロイもされない。

## 使い方

1. **仕掛ける**: x.com で自分のプロフィールを開き、ブックマークレットを押す（または F12 → Console に `followers.js` を丸ごと貼る。Chrome は最初に `allow pasting` と打つ必要あり）。右上に枠が出る
2. **フォロワー**: 「フォロワー」を開く → 勝手に下までスクロールする → 「終わり」と出たら「今回分をコピー」→ スプシに貼る
3. **フォロー**: 上のタブで「フォロー中」に切り替える → 同じように「今回分をコピー」→ 貼る

- 先に仕掛けてから一覧を開くこと。一覧を開いた後に押すと最初の約20人が取れない（枠にそう出る。プロフィールに戻って開き直せばよい。再読み込みはしない）
- 終わったときの人数が、プロフィールに出ている数とだいたい合っているか見ておく

## スプシ

「今回分をコピー」で、見出し行のついた TSV がコピーされる。シートを1枚（またはフォロー用・フォロワー用の2枚）作って、前回分の下に貼り足していく。

| 日付 | 区分 | user_id | ID | 名前 | プロフィール | 場所 | URL | フォロワー数 | フォロー数 |
|---|---|---|---|---|---|---|---|---|---|

- 日付はコピーした日（日本時間）。区分は「フォロー」か「フォロワー」
- **user_id** は X の中の番号で、@ID を変えても変わらない。比べるときはこれで同じ人を見分ける。19桁あってスプシで数値にされると桁が落ちるので `x:` を付けている
- プロフィールの改行は `⏎` に置き換えている。t.co の短縮URLは元のURLに戻している
- 2回目からは見出し行は消して貼ってよい

## 前回との比べ方

コピーを押すと、その回の分がこのブラウザ（x.com）にも残る。次の回に、終わったあと次のどちらかを押す。

- 「**前回（日付）と比べる**」: 同じブラウザで前にコピーした分と比べる
- 「**スプシの前回分を貼って比べる**」: 別のPCのときや、ブラウザのデータを消したとき。スプシの記録を見出し行ごとコピーして貼る（シートを丸ごと貼ってもよい。同じ区分の一番新しい日付の分と比べる）

違いは枠に出る。「違いをコピー」で `日付 / 区分 / 変化 / user_id / ID / 前 / 今` の TSV になるので、「変化」シートに貼り足しておくと履歴になる。
「減った」は、フォロー解除・凍結・アカウント削除のどれかで、区別はつかない。

## ファイル

| ファイル | 中身 |
|---|---|
| `followers.js` | 本体。コンソールに貼るのもこれ |
| `bookmarklet.txt` | ブックマークレット。中身をまるごと、ブックマークの URL 欄に貼る |
| `build.js` | `followers.js` を直したら `node x-followers/build.js` で `bookmarklet.txt` を作り直す |

X の画面の作りが変わると取れなくなることがある（0人のまま増えないなど）。そのときは `followers.js` の `walk()` / `add()` を応答に合わせて直す。
